===========================================
DATABASE SCHEMA NORMALIZATION MAPPING
===========================================

NAMING CONVENTIONS:
- All column names: snake_case
- Foreign keys: {singular_table}_id
- Dates: _at suffix (created_at, updated_at)
- Boolean flags: is_ prefix or _enabled suffix
- Table names: plural (items, software, etc.)

===========================================
SUMMARY OF KEY IMPROVEMENTS
===========================================

1. Consistent snake_case naming
2. Foreign keys follow {table}_id pattern
3. Remove 's' prefix from software columns
4. Standardize type table names with underscores
5. Clear date/time field naming (_at suffix)
6. Boolean fields use is_ prefix
7. Descriptive names (statusdesc → name)
8. Junction tables use plural_plural pattern
9. Remove duplicate columns (files.type vs files.ftype)
10. Add missing useful columns (invoices.invoice_number)
